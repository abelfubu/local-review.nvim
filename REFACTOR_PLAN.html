🧱 local-review.nvim — Layer Refactor

Goal: fix the layer violation (export/gh_pr → comments) by making each module a deep module: a small interface hiding substantial functionality. Rules flow down, never up.

1 · Layer map (target state)

presentation  init · ui · markers · telescope        → keymaps, windows, signs, pickers
application   comments · export · gh_pr · gh_pr_comments → workflows, orchestration
infrastructure storage · context                     → persistence, paths, repo root
domain        comment_store · positioning            → vim-free rules (busted-tested)
📐 Deep module test (Ousterhout): the interface should be much smaller than the implementation behind it. storage exposes ~6 functions but hides: scope file layout, sha256 filenames, LWW merging, JSON, normalization-at-boundary. comment_store exposes rules but hides anchoring, reconciliation, sorting, remote policy.
